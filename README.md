## Featured Projects

### Edu-SLM — Domain-Specific Educational Language Model

* Built a domain-specific educational language model using LoRA fine-tuning and RAG pipelines.
* Integrated FAISS vector retrieval and semantic embeddings for curriculum-based question answering.
* Achieved strong benchmark performance while improving response reliability and reducing hallucinations.

### UPESCSA.in — Official UPES-CSA Platform

* Developed and maintained the official UPES-CSA platform using the MERN stack.
* Managed deployment using Docker, Nginx, and AWS EC2.
* Streamlined registrations, event management, and technical operations.

### TheGeetaWay — AI-Powered Guidance Platform

* Built a semantic search and retrieval-based platform powered by Llama 3.
* Implemented contextual response generation using FAISS and Sentence Transformers.

### ASL Recognition System

* Developed a real-time sign language interpretation system using YOLO, OpenCV, and MediaPipe.
* Focused on low-latency gesture recognition with high detection accuracy.
